# Beity AI

واجهة عربية لمنصة بيتي. الواجهة صفحات HTML، وواجهة API تعمل كـ Vercel Functions، وتُخزَّن بيانات المشاريع والصور في Supabase.

## إعداد Supabase مرة واحدة

1. أنشئ مشروعًا في Supabase.
2. افتح `SQL Editor` وشغّل محتوى `supabase/schema.sql` لإنشاء جدول المشاريع ومخزن صور خاص وسياسات RLS.
3. من إعدادات المشروع انسخ `Project URL` والمفتاح العام `anon` أو `publishable`.
4. أضف القيمتين كمتغيرات بيئة في Vercel كما هو موضح أدناه. يرسل الموقع المفتاح العام للمتصفح من `/api/config` وقت التشغيل؛ لا يُحفظ أي مفتاح في ملفات GitHub.

المفتاح العام مخصص للمتصفح ومحمي بسياسات RLS. لا تضع `service_role` أو أي مفتاح سري في ملفات الموقع أو GitHub.

## التشغيل محليًا

ثبّت Node.js، ثم من مجلد المشروع شغّل:

```powershell
npm run dev
```

افتح `http://localhost:8000`. لتفعيل الـ API محليًا، انسخ `.env.example` إلى `.env` وأضف رابط Supabase والمفتاح العام. ملف `.env` مستثنى من Git.

## النشر على Vercel

1. ارفع محتويات المستودع إلى GitHub.
2. في Vercel اختر `Add New > Project`، ثم اربط مستودع GitHub واضغط `Deploy`.
3. من إعدادات المشروع في Vercel افتح `Environment Variables` وأضف:
   - `SUPABASE_URL` = Project URL من Supabase.
   - `SUPABASE_ANON_KEY` = المفتاح العام anon/publishable.
4. أعد النشر بعد إضافة المتغيرات.
5. افتح رابط `.vercel.app` الذي يعرضه Vercel. ملف `vercel.json` يوجه `/` إلى الصفحة الرئيسية ويترك `/api/*` لوظائف الـ API.

بعدها أي شخص يفتح رابط Vercel يرى الموقع، ويمكنه إنشاء حساب وتسجيل الدخول وحفظ مشاريعه الخاصة. اجعل `SUPABASE_URL` و`SUPABASE_ANON_KEY` مضبوطين في Production في Vercel.

## حدود النسخة الحالية

حفظ المشاريع والحسابات ورفع الصور يعمل عبر Supabase. توليد الرندر بالذكاء الاصطناعي، الدفع، ورسائل واتساب ليست موصولة بخدمات فعلية بعد. الصور الموجودة في صفحة العرض أمثلة توضيحية.
